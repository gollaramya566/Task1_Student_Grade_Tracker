# CodeAlpha Java Programming Tasks

This repository contains complete console/GUI Java implementations for all four tasks listed in the provided CodeAlpha Java Programming Tasks document.

## Included Tasks

1. **Student Grade Tracker**
   - Input and manage student grades
   - Calculate average, highest and lowest scores
   - Uses `ArrayList`
   - Displays a summary report
   - Console-based interface

2. **Stock Trading Platform**
   - Simulated stock market data
   - Buy and sell operations
   - Portfolio tracking
   - OOP classes for stocks and users
   - File I/O saves the portfolio to `portfolio.txt`
   - Console-based interface

3. **Artificial Intelligence Chatbot**
   - Java Swing GUI
   - Basic NLP preprocessing/normalization
   - Rule-based intent matching and responses
   - Answers common Java/OOP/NLP questions
   - Interactive real-time chat

4. **Hotel Reservation System**
   - Search hotel rooms
   - Standard, Deluxe and Suite categories
   - Make and cancel reservations
   - Simulated payment
   - Booking details view
   - OOP + file I/O using `reservations.txt`
   - Console-based interface

## Requirements

- Java JDK 17 or newer is recommended.
- No external libraries are required.

## Compile

Open a terminal inside the required task folder and run:

```bash
javac StudentGradeTracker.java
java StudentGradeTracker
```

For the other tasks, replace the class/file name accordingly.

## GitHub

Create a GitHub repository named something like:

`CodeAlpha_Java_Projects`

Upload all task folders and this README. Then use the repository URL in the CodeAlpha submission form and LinkedIn post as required by the assignment instructions.
