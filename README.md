# Student Grade Tracker

## CodeAlpha Java Task 1

A Java console-based Student Grade Tracker that allows users to enter student grades and calculate:

- Average score
- Highest score
- Lowest score
- Class average

## Technologies Used

- Java
- ArrayList
- Object-Oriented Programming

## How to Run

Compile:

javac StudentGradeTracker.java

Run:

java StudentGradeTracker
